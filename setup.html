更新日志

v1.8.6（正式版26.9.26）更新日志

1. 性能优化：移除大量 backdrop-filter、关掉 background-attachment: fixed、transition: all 改为具体属性、去掉低价值无限动画，滚动明显比之前顺。

2. 手机版整体重排：不再分"仪表盘 / 内容页"上下两套系统，改为一路滑到底，顶栏下面直接轮播，往下是日历 + 倒数日、动态、产品、文章、联系、版权。

3. 手机版轮播：贴顶、全宽、无圆角，高度压缩到 200~240px，字号和按钮尺寸同步缩小。

4. 手机版日历 + 倒数日：并排两列等宽显示，日历在左、倒数日在右，各自独立滚动。

5. 手机版底部标签栏：股市、资讯、搜索、AI、网盘五个标签固定贴底，点击后从下方弹出模拟弹窗，点 ✕ 或点遮罩退出。

6. 最新资讯接入：数据来自 uapis.cn 热榜接口，默认显示微博热榜前 30 条，超出面板高度的部分在面板内滚动，不影响整页。

7. 资讯平台切换：面板标题右侧加下拉，可切微博、知乎、B站、抖音、百度、头条，切换即时刷新。

8. 资讯点击跳转：默认点击条目在新标签页打开原链接；设置弹窗里可切换为"搜索标题"，改为用百度搜索该标题后再打开。

9. 组件显隐控制：右下角账号框底部加"▼ 查看更多"按钮，点一下隐藏 4 个可切换组件，按钮变"▲ 收起组件"，再点一下恢复。

10. 设置弹窗新增"显示组件"分组：日历/倒数日、股市、资讯、通知四项，每项带开关圆点，点一下立刻切换显隐，状态存 localStorage，刷新不丢。

11. 倒数日字段类型修复：Airtable 表的"日子"和"有效期"是数字类型，写入前先转 Number；有效期为空时传 null 而不是空字符串。之前 422 的问题已解决。

12. 电脑版滚动切换优化：去掉滚轮 deltaY 最小阈值限制，鼠标滚一格也能切换；手机版不参与上下切换，走自然滚动。

13. 手机版页面结构修复：HTML 和 body 高度改回 auto，两个页面取消 fixed 定位，允许整页滚动，解决之前"滑不动"的问题。

【不足一】股市模块仍是占位，等待 QOS 的 key 和具体接口定义（URL 路径、请求方式、参数、返回字段）。

【不足二】设置弹窗还没重构。你规划的"两栏布局 + 显示 / 主题 / 个性化 / 账号和安全"四大块还没做，当前仍是单栏按钮列表。

【不足三】登录流程未调整。目前登录后仍跳 user.html，还没改成回主页，顶栏头像也还没接"直接打开设置里的账号与安全"。

【不足四】手机版间距、字号是按估算值给的，实际观感需要你在真机上看一遍，可能要微调轮播高度、日历格子大小、标签栏高度。

【不足五】组件隐藏后原位置留空，不会自动挤压其他框。这是为了保证网格布局稳定，如果你希望隐藏后其他框填上来，需要重做布局逻辑。

【不足六】Airtable 可写令牌仍暴露在前端 dashboard.js 里，正式上线前建议走 Cloudflare Worker 代理。

【不足七】uapis.cn 匿名调用有免费额度，用完后会返回 429，需要注册账号拿 key。到时可在 URL 后加 &key=你的key。

v1.8.3（预览版26.9.25）更新日志

1. 新增"仪表盘/内容页"双页面系统：上半部分为独立起始页，固定一屏；下半部分为原有内容，从下滑入，两套系统完全分离，互不干扰。

2. 仪表盘按线框图重排：左上为日历+倒数日，右上为轮播（整体从原位置移入），下排从左到右为股市、最新资讯、最新通知、搜索框+账户中心。

3. 日历支持翻月，自动高亮"今天"以及当月存在倒数日的日期。

4. 倒数日接入新的可写 Airtable 令牌（Base：appFSBs4szXKsDTx9），用户可点击"＋ 新建"按钮，填写名称、日子、创建人、有效期后提交，任意用户均可新增。

5. 倒数日支持按日期筛选（下拉框），过期项自动隐藏；显示内容为"还有 X 天 / 就是今天 / 已过去 X 天"。

6. 最新通知接入原有只读 Airtable 令牌（Base：app9G6YeDcFq7g09r）的"最新通知"表，按数据倒序显示，最新的通知排最前。

7. 搜索框支持自选搜索引擎（百度、Bing、知乎、抖音、小红书、稀土掘金），并可切换"搜索本页内容"（用 window.find），搜索跳转一律新标签页打开，不在原页面内跳转。

8. 账户中心未登录时显示"你还没有登录，请先登录"及登录按钮；已登录时显示头像、用户名、邮箱，下方横线分隔，再下面是 5 个演示快捷链接（点击随机跳转，后期可自行修改）。

9. 设置栏从原来的长条形改为弹窗形式，类似电脑应用窗体，不可拖动，右上角有关闭，底部有"保存"按钮。原来设置栏里的所有项（深色模式、通知、语言、数据统计、实验功能）全部迁移到弹窗内。

10. 版本更新日志整块替换为"📄 点击此处显示更多文本信息"框，点击在新标签页打开同目录下的 setup.html。

11. 顶栏保持不变；原有 script.js 的逻辑完全未改动；下方动态、产品、文章、联系等所有内容保持原样。

12. 页脚版权行做多层兜底：footer 底部 padding 加至 90px，footer-copy 单独设置可见性，内容页内大胶囊上移 100px，避免遮挡"All Rights Reserved"。

【不足一】股市模块目前仍是占位状态，仅保留容器和样式。你 docx 里只给了 QOS 行情 API 的首页 https://qos.hk/ 和示例页 https://qos.hk/example.html，没有给具体的接口地址、请求方式、返回字段，我无法凭空写渲染逻辑。需要你补充 QOS 的实际调用方式（REST 还是 WebSocket、是否需要 key、返回 JSON 结构），才能接入。

【不足二】最新资讯模块按你的要求先空着，只显示"待接入"。后续需要你指定数据源（是热搜榜 uapis.cn，还是别的接口）才能填充。

【不足三】倒数日"有效期"字段的语义是我按"过期后自动隐藏"实现的。如果本意是"有效期内可编辑、过期后锁定"或别的含义，逻辑需要调整。

【不足四】setup.html 尚未创建，需要你后续补上，否则"点击此处显示更多文本信息"框点击后会打开 404。

【不足五】账户中心的 5 个快捷链接现在是"随机跳转"的演示行为，图标和文字也都是占位，需要你后期自行改为固定链接。

【不足六】轮播在新仪表盘 panel 内的高度、字号经过多轮调整。若你的屏幕分辨率特殊（比如超宽屏或小笔记本），轮播可能仍显得偏挤或偏空，需要按实际屏幕微调。

【不足七】页面滚动切换用滚轮触发，阈值设为 deltaY 8、锁 900ms。部分鼠标滚轮步进较大时可能一次跳两下，或触控板用户觉得切换太灵敏/太迟钝，需要按手感微调。

【不足八】Airtable 两个令牌都写在前端 JS 里，倒数日的可写令牌暴露在客户端，任何人打开 F12 都能看到并用它写入数据。这是当前架构的固有风险，正式上线前建议改为通过 Cloudflare Worker 代理写入，不在前端直接暴露令牌。
